## Native notification investigation — integration pending

The pinned Media3 1.10.1 [notification manager](https://github.com/androidx/media/blob/1.10.1/libraries/session/src/main/java/androidx/media3/session/MediaNotificationManager.java) bases foreground retention on public playback state and an inactivity timeout; asynchronous notification callbacks can update foreground state directly. Simply reporting the keepalive player as paused, or hiding its progress bar, does not provide a complete truthful-state and retention solution. The supported [SimpleBasePlayer](https://github.com/androidx/media/blob/1.10.1/libraries/common/src/main/java/androidx/media3/common/SimpleBasePlayer.java) supplies consistent state/listener handling for a native semantic adapter.

The next native integration must project actual Ready, countdown, playback, pause, overlap and Recovery states; publish only supported semantic controls; guard stale notification inputs; and retain foreground notification ownership independently from a silent transport clock. It must preserve native command admission, urgent stop/panic and deliberate recovery, including notification updates and retention beyond the default inactivity period. No native lifecycle workaround is included in the shared-clock change, and the prepared Android media-card issue remains open until built and device-verified.
