# Isolated backup/recovery audit

This separate same-test-signer instrumentation is never registered or shipped in the product. Use only on the owned `ShowControl_LibraryLoad_QA` fresh-data emulator at `emulator-5564`. Its data directory must be under this task's workspace; never point it at an existing user's library. The wrapper requires the exact installed target/helper APK checksums and idle service/instrumentation state. It reads no provider keys or user media and makes no network requests.

Import the UUID-labelled original synthesized fixture through the ordinary Android picker. Audit accepts exactly 1, 2 or 4 fixture shows, checks complete tuning/order/Hits, scoped disabled voice data, images/fallback, retained selection, distinct show/set/revision/profile identities and unbound portable safety mappings. Cue IDs remain scoped to each show, as documented by the portable format; repeated imports need not change those IDs. It opens SQLite read-only, checks native quick-check/schema, verifies actual canonical media bytes, rejects unrelated work and requires empty staging. This does not inject a delayed database failure; the deferred-read recovery race is covered by real-SQLite controlled tests separately.

After exporting the two-show library normally, `copy-export` first performs the same audit, then publishes one fresh exact `roundtrip.zip` through Android MediaStore Downloads, with pending/complete ownership and checksum verification. It never modifies the saved archive or database and refuses overwrite. An unpublished failure deletes only the row it just created. Reimport that public copy through the app and audit four independent shows. The earlier external-app-directory copy remained inaccessible to the shell under scoped storage; its receipt is retained and it must not be represented as a successful file handoff.

An observation timeout is not permission to restart the target, rerun an operation or clear data. Reconcile the same recorded PID/instrumentation handle. Preserve failed evidence. Close only the owned idle emulator at the end; preserve the original test emulator's files. This evidence does not satisfy physical iOS/Android, cross-platform sharing, genuine native faults, long runs or store/customer certification.
